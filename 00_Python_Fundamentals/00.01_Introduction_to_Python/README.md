# What is Programming?

Programming is the process of giving instructions to a computer.

Imagine asking someone to make a cup of tea.

You might say:

1. Boil water.
2. Add tea leaves.
3. Pour into a cup.
4. Add sugar.
5. Serve.

These instructions are called an **algorithm**.

Similarly, computers need instructions written in a language they understand.

These instructions are called **programs**.

---

# What is Python?

Python is a **high-level programming language** created by **Guido van Rossum** and first released in **1991**.

Python allows programmers to write instructions using simple English-like syntax.

Example:

```python
print("Hello, World!")
```

Even someone new to programming can guess what this code does.

It prints:

```
Hello, World!
```

# How Python Works

Python is an interpreted language.

The execution flow is:

```
Python Code
      │
      ▼
Python Interpreter
      │
      ▼
Bytecode (.pyc)
      │
      ▼
Python Virtual Machine (PVM)
      │
      ▼
Operating System
      │
      ▼
Output
```
