# Practice Exercises

## Easy

1. Create a variable called `name` and store your name.
2. Create a variable called `age`.
3. Print both variables.

---

## Medium

Create variables for:

- Product name
- Price
- Quantity

Calculate the total bill.

---

## Challenge

Ask the user for:

- Name
- Age
- City

Print a formatted welcome message using all three variables.

Example:

```
Hello Alice!
You are 20 years old.
You live in London.
```
