## Multiple Choice

### 1. Which operator assigns a value to a variable?

- A. ==
- B. =
- C. :=
- D. +

**Answer:** B

---

### 2. Which is a valid variable name?

- A. 2age
- B. student-name
- C. student_name
- D. class

**Answer:** C

---

### 3. Python is:

- A. Statically typed
- B. Dynamically typed
- C. Untyped
- D. None

**Answer:** B

---

### 4. What will this print?

```python

print(x)
```

- A. 5
- B. 8
