# Practice - Operators

Practice is the key to mastering operators. These exercises are organized by difficulty to help you gradually build confidence.

---

# Easy

## 1. Add Two Numbers

Write a program to add two numbers and display the result.

Example:

```python
Input:
10
20

Output:
30
```

---

## 2. Calculate Area of a Rectangle

Use the multiplication operator to calculate the area.

Formula:

Area = Length × Width

---

## 3. Find Even or Odd

Use the modulus operator (`%`) to determine whether a number is even or odd.

Example:

```text
Input:
18

Output:
Even
```

---

## 4. Compare Two Numbers

Write a program that displays whether:

- First number is greater
- Smaller
- Equal

Use comparison operators.

---

## 5. Compound Assignment

Start with:

```python
score = 50
```

Perform the following operations:

- Add 10
- Multiply by 2
- Subtract 15
- Divide by 5 (floor division)

Print the final score.
