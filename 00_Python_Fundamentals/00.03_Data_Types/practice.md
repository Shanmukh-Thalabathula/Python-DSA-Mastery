# Practice

## Easy

1. Create one variable of each built-in numeric type.
2. Print the type of each variable.
3. Create a list containing five integers.
4. Create a tuple containing your favorite fruits.
5. Create a dictionary describing yourself.

---

## Medium

1. Convert user input into an integer.
2. Remove duplicate numbers using a set.
3. Demonstrate mutable vs immutable objects.

---

## Hard

Write a program that stores student information in a dictionary containing:

- Name
- Roll Number
- Marks
- Subjects (List)

Print the dictionary neatly.
